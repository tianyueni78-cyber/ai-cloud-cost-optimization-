# GPU成本基线报告

## 1. 指标口径

分析范围为2025年8月至2026年7月，主时间口径使用账单的业务使用期间，辅助口径使用发票月份。

```text
GPU账单总成本
= Σ net_cost_usd
其中 charge_type ∈ {Usage, Commitment, Credit, Adjustment, Support}
```

`UnusedCommitment` 是已计入采购承诺中的未使用部分，仅作为管理指标单独展示，不重复加入总成本。

## 2. 核心结果

| 指标 | 结果 |
|---|---:|
| 12个月GPU账单总成本 | $21,460,534.39 |
| 月均成本 | $1,788,377.87 |
| 单独展示的未使用承诺成本 | $7,839,370.88 |
| 成本最高的业务月份 | 2026-07，$1,867,544.85 |
| 成本最低的业务月份 | 2025-09，$1,684,712.63 |
| 最大月度增长 | 2026-03，+10.62% |
| 最大月度下降 | 2026-04，-7.62% |

## 3. 采购方式结构

| 采购方式 | 总成本 | 占比 |
|---|---:|---:|
| Savings Plan | $6,041,046.61 | 28.15% |
| Reserved | $5,838,972.84 | 27.21% |
| On-Demand | $5,506,920.77 | 25.66% |
| Owned | $4,073,594.17 | 18.98% |

承诺型采购（Reserved和Savings Plan）合计占55.36%，但该比例本身不能证明买多或买少；后续必须结合稳定负载、增长、SLA和未使用承诺分析。

## 4. 费用类型对账

| 费用类型 | 账单行 | 净金额 | 是否计入总成本 |
|---|---:|---:|---|
| Usage | 696 | $21,404,795.27 | 是 |
| Support | 84 | $122,090.06 | 是 |
| Adjustment | 43 | $5,001.51 | 是 |
| Credit | 2 | -$71,352.45 | 是 |
| UnusedCommitment | 384 | $7,839,370.88 | 否，单独展示 |

本期没有独立的 `Commitment` 账单行。允许的费用类型不要求每一种都必须出现，因此不能仅凭缺少该类型判定数据错误。

## 5. 使用月份与发票月份

业务使用期间完整覆盖12个月。发票月份覆盖14个月，其中2026年8月和9月分别确认 $157,302.70 和 $1,518.59，属于观察期内用量的延迟入账。

因此：

- 分析业务成本趋势使用业务使用月份；
- 解释财务入账和现金视图使用发票月份；
- 不能按发票月份把后两个月误判为业务成本骤降。

## 6. 验证结果

- `billing_line_id` 重复数为0；
- 金额公式不一致账单为0；
- 业务使用范围为2025-08-01至2026-07-31；
- 查询只读取清洗后的账单表，没有连接维表，因此不存在JOIN放大成本；
- 费用类型小计能够还原总成本，`UnusedCommitment` 未重复计入。

## 7. 阶段结论

公司12个月GPU账单总成本为2,146.05万美元，月度业务成本总体位于168.47万至186.75万美元之间。采购成本分布较为分散，承诺型采购占比超过一半，同时存在783.94万美元的未使用承诺管理口径。

这些结果回答了“花了多少钱、何时发生、怎样收费”，但尚不能单独证明浪费及其原因。下一阶段需要按团队、产品、资源池和GPU型号进行成本归因，并与业务量、利用率、SLA和事件共同解释。
