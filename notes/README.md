# 项目学习笔记

这里记录实际学习过程，与 `learning/` 中的操作指南分开：

- `learning/`：标准做法，回答“应该怎么做”。
- `notes/`：本人实践记录，回答“我实际做了什么、得到什么、怎样理解”。
- `reports/`：正式业务交付物，面向招聘方和管理层。

## 命名规则

按项目阶段编号：

