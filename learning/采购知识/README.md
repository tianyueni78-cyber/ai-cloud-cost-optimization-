# 采购知识

这里不做采购百科，只整理本项目完成采购组合、容量和成本优化决策所必需的知识。它回答“当前项目为什么要懂这一点、用它判断什么”，不负责讲 SQL 或 Pandas 语法。

## 当前核心文档

[项目所需GPU采购知识树](01_GPU采购基础与分析知识树.md)

```text
先明确项目要做的决定 → 认识数据里的采购方式
→ 分清采购方式与费用类型 → 按项目问题使用公式
```

遇到采购问题时，先在知识树定位问题属于“钱、资产、使用、约束还是原因”，再进入数据映射和代码。
