# 代码翻译与自检

这组手册用于把业务判断翻译成可以审查的SQL或Pandas，并建立不依赖AI的固定自检程序。

## 阅读顺序

```text
1. 先用《指标与数据映射》完成六定
2. 要写SQL → 打开《SQL翻译模板》
3. 要写Pandas → 打开《Pandas翻译模板》
4. 代码完成 → 打开《固定自检程序》逐项检查
5. 不知道完整过程怎样串起来 → 查看《GPU成本完整范例》
```

## 四份手册

1. [SQL翻译模板](01_SQL翻译模板.md)：业务动作、可复用SQL、占位符说明和常见错误；
2. [Pandas翻译模板](02_Pandas翻译模板.md)：同一业务动作的Pandas写法与检查；
3. [固定自检程序](03_固定自检程序.md)：语法、粒度、重复、公式、JOIN、对账和结果边界；
4. [GPU成本完整范例](04_GPU成本完整范例.md)：从六定、翻译、查询到验证的完整示范。

## 怎样看占位符

模板中的 `【】` 必须替换。说明直接写在同一行或上一行：

```sql
SELECT
    【分组字段】,              -- 替换为“按什么分别看”；例：invoice_month
    SUM(【数值字段】) AS total -- 替换为需要加总的数字；例：net_cost_usd
FROM 【表或读取表达式】        -- 替换为主表；例：clean_billing
GROUP BY 【分组字段】;
```

右侧示例只演示填什么，不代表其他项目也使用相同字段。

## 使用原则

- 可以复制模板，不要求背整段代码；
- 复制后必须能逐行翻译回业务语言；
- 项目字段、枚举和路径允许查询；
- 每次只替换当前问题需要的部分；
- 代码能运行只是通过语法关，必须继续完成固定自检；
- AI生成的代码也按同一标准审查。
